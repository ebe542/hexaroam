# Firmware

Rust firmware for the central Pico and optional servo-output expansion modules. Start with one servo. The selected board is Raspberry Pi Pico with RP2040, targeting `thumbv6m-none-eabi`. The embedded toolchain setup, pin allocation, and signal-generation implementation remain pending. See [hardware references](../hardware/references/README.md) for the archived datasheets. No buildable Cargo package exists yet.
